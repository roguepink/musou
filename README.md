# 侍無双

門をくぐって仲間を増やせ!侍と忍者の大軍で、鬼も大将もなぎ倒す。

**遊ぶ: https://roguepink.github.io/musou/**

## 遊び方

- 指で左右に動かすだけ(PC は ← → キー、M で音、P で一時停止)。仲間は自動で撃つ
- 青い門で仲間が増え、赤い門で減る。**門を撃つと数字が上がる**(赤を青に変えられる。かけ算の門は ×2 まで)
- 木箱を壊すと 武器(弓矢→手裏剣→火縄銃→火矢→焙烙玉→雷刀)・援軍・攻撃力アップ
- 最後に大将(赤鬼・大天狗・がしゃどくろ・大猪・大蛇・九尾の狐・土蜘蛛・怨霊・龍神・鬼将軍 をくり返す)。赤い丸はよける
- 景色は 桜街道・竹林・夜の城下町・雪の峠・炎の合戦場 をくり返す。陣は終わりなし(だんだん強くなる)

## ファイル

- `index.html` 画面の枠(タイトル・突破・討死・ひと休み)/ `game.js` ゲーム本体(絵も音もここで作る。外のファイルなし)
- 確認用: アドレスの末尾 `#auto`(おまかせ操作)/ `#auto4`(4倍速)/ `#auto-s5`(第5陣から)/ `#play`
- むずかしさは `game.js` の `expN`(ふつうの人数)・`D`(陣ごとの強さ)・`spawnWave`/`spawnBoss` の数字で変える

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ遊べる
- **LINE の中で開いたときは、ホーム画面に入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。一度開けば電波がなくても遊べる

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)を変えたときだけ
