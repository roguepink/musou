# 侍無双

門をくぐって仲間を増やせ!侍と忍者の大軍で、鬼も大将もなぎ倒す。

**遊ぶ: https://roguepink.github.io/musou/**

## 遊び方(2026-11-10 作り直し)

- 後ろから見た立体の画面。奥から敵の大軍が押し寄せる。指で左右に動かすだけ(PC は ← →・M で音・P で一時停止)
- 道は3列。**青い門**で仲間が増え、**赤い門**で減る。門を撃つと数字が上がる。**金の門**は武器
- 主の武器(1つ): 弓矢 → 手裏剣 → クナイ → 火矢 → 火縄銃 → 大筒(同じ門で Lv が上がる)
- 助っ人の武器(いくつでも・Lv1〜3): 爆竹・焙烙玉・花火・雷・風魔手裏剣・妖刀・鎖鎌
- ドキドキの場面: 敵の大軍の来襲・騎馬隊の突撃(赤い列からよける)・弓隊の矢の雨・大丸太
- 大将: 赤鬼・がしゃどくろ・土蜘蛛・八岐大蛇・鬼武者・龍神。じりじり迫り、目の前まで来ると仲間がどんどん減る。なぎ払い・突進・炎・岩の雨・手下呼び
- 景色: 夕暮れの桜街道・霧の竹林・月夜の城下町・吹雪の峠・炎上する合戦場・黄泉の道

## ファイル

- `index.html` 画面の枠 / `game.js` ゲーム本体 / `art.js` 絵(全部コードで描く) / `audio.js` 音と曲(太鼓・三味線・尺八ふう。大将戦は別の曲)
- `fonts/` 筆文字(Yuji Boku)と太字(Dela Gothic One)の、使う字だけ。字を足したら `tools/make_fonts.py` で作り直す(OFL)
- 確認用: アドレスの末尾 `#auto`(おまかせ操作)/ `#auto4`(4倍速)/ `#auto-s5`(第五陣から)/ `#play`
- むずかしさは `game.js` の `expN`(ふつうの人数)・`D`(陣ごとの強さ)・`spawnWave`/`spawnRush`/`spawnBoss` の数字で変える
  - 2026-11-10 の調整: おまかせ操作で 第一〜三陣はぎりぎり突破、四〜九陣は大将をあと少しまで追いつめて負けることが多い

## LINE で送る・ホーム画面に入れる

- 上のアドレスを LINE に貼れば、タイトルと絵つきの紹介が出る。タップするとすぐ遊べる
- **LINE の中で開いたときは、ホーム画面に入れられない。**メニューから「Safari で開く」(iPhone)/「他のアプリで開く」→ Chrome(Android)を選んでから入れる
  - iPhone(Safari): 共有ボタン →「ホーム画面に追加」 / Android(Chrome): メニュー(︙)→「アプリをインストール」
- 入れたあとは全画面で起動。一度開けば電波がなくても遊べる

## 直して公開するとき

- `main` に push すれば公開される(GitHub Pages)。電波のある人は、**次に開いたとき**に新しい版になる(`sw.js` は まずネットで最新を取りにいく)
- `sw.js` の `VERSION` を上げるのは、覚えるファイル(`FILES`)を変えたときだけ
